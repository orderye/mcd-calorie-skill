# 营养表结构与解析规范（T1 产出）

> 数据来源：`list-nutrition-foods`，抓取时间 2026-10-09 23:44:25 GMT+8。
> 原始快照：`fixtures/nutrition.raw.txt`。

## 1. 响应结构

```json
{"success": true, "code": 200, "message": "请求成功", "data": "<紧凑格式字符串>"}
```

`data` 是**单个字符串**（非数组、非对象），需要自行解析。

## 2. 紧凑字符串格式（实测）

```
[160]{productName,nutritionDescription,energyKj,energyKcal,protein,fat,carbohydrate,sodium,calcium}:
  猪柳麦满分,null,1288,308,16,16,24,781,213
  猪柳蛋麦满分,null,1618,387,23,21,25,846,243
  ...
```

- 第一行：`[条目数]` + 花括号包裹的**表头（字段顺序）** + `:`。
- 之后每行一条记录，**两空格缩进**，逗号分隔，共 9 列，顺序固定。
- 行内字段本身**不含逗号**（商品名中的引号【】“”均安全），可按 `,` 直接 split。

## 3. 字段与单位（已核对，Q3 结论）

| 列 | 字段 | 单位 | 说明 |
|---|---|---|---|
| 1 | productName | — | 商品名，是匹配主键 |
| 2 | nutritionDescription | — | 类比描述（"能量约清水1杯"），多为 `null` |
| 3 | energyKj | **kJ** | 每份 |
| 4 | energyKcal | **kcal** | 每份。推荐引擎使用此列 |
| 5 | protein | **g** | 蛋白质 |
| 6 | fat | **g** | 脂肪 |
| 7 | carbohydrate | **g** | 碳水 |
| 8 | sodium | **mg** | 钠 |
| 9 | calcium | **mg** | 钙 |

单位核对依据：猪柳麦满分 308 kcal / 蛋白 16 g / 钠 781 mg，与常见汉堡营养量级一致；kJ/kcal 比值 ≈ 4.18 全表吻合；钠若为 g 则 781g 荒谬，故为 **mg**。

## 4. 数据质量要点（解析器必须处理）

1. **重复行**：`小杯玉米杯`、`纯牛奶（盒装）` 各出现 2 次（数值一致）→ 解析后需**去重**（同名取首条并计数）。
2. **零热量条目**：`无糖可口可乐中/大/小杯` 全 0（但碳水 1g、钠 35mg）；`纯悦` 全 0 且描述"能量约清水1杯" → 0 是**合法值**，与"未知"严格区分。
3. **杯型条目存在（Q4 结论）**：可乐/雪碧/柠檬红茶/牛奶/奶铁/美式/黑巧等均有 中杯/大杯/小杯 三档，热量不同。**加料条目不存在**（无酱包/奶油球/糖包行）→ 加料热量确实无法从本表取得，维持"不计入并告知"策略。
4. **无 `-poolN` 后缀、无"加…"行**：归一化规则主要应对**菜单侧**命名，营养表侧较干净。
5. **kcal 异常抽查**：`大杯鲜萃咖啡 13 kcal` vs `小杯鲜萃咖啡 15 kcal`（大杯反而低）——官方原始数据如此，不做修正，照实输出。
6. 全表 **160 行**（含 2 行重复 → 去重后 158 个唯一商品名）。

### 5.1 ★ 数量后缀剥离导致的伪歧义（2026-10-10 修复）

`normalize_query` 会剥掉「N块 / N杯」等数量后缀，好让「麦麦脆汁鸡1块」去匹配「麦麦脆汁鸡-琵琶腿」。
但营养表**本身就收录了带数量的条目名**（`麦乐鸡5块` 213 kcal、`麦乐鸡4块` 170 kcal），
于是「麦乐鸡5块」被剥成「麦乐鸡」→ 前缀匹配到 4 块/5 块两条 → 判为 `ambiguous`。

实测影响：历史订单 8 笔里「麦乐鸡5块」被误判歧义，**213 kcal 未计入**，整单 715 kcal（真值 928）。
歧义是「规格缺失」语义，不该出现在规格明确的订单子项上。

修复：在「归一化精确」之后、别名之前插入 **1.5 原始键精确**（`normalize_name(name)` 直接查表，
method=`exact-qty`）。查询侧带数量且营养表有同名条目 → 精确命中；带数量但表里没有
（如「麦麦脆汁鸡1块」）→ 照旧走前缀/歧义。修复后历史订单歧义 1 → 0，评测仍 PASS（92.3%）。
